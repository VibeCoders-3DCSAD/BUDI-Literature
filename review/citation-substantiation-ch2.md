## 3. Formula verification (Chapter 2 V5 vs. implementation)

| MDA | Correct, clarified | Implementation uses the previous **actual** value (`y_prev`) in both sign comparisons, matching the chapter formula. A clarifying sentence and footnote were added; textbook MDA sometimes uses the previous forecast. |
| RMSE | Correct | Same source. |
| Rule Coverage, EOA, TCPR, CSR, BUR | Correct | Standard ratios; match the definitions described in the text. |
| MILP general form | Correct | Standard `max Z=Σc_jx_j` subject to `Σa_ijx_j≤b_i`, `x_j≥0`, some `x_j∈Z`. |

| Accuracy, Precision, Recall, F1 | Correct | Standard confusion-matrix definitions. |

## 5. Other editorial flags

- **SARIMA equation** was missing from V5 (see section 3). Restored and flagged.
- **Figure 1 (pseudocode) and Figure 3 (sample data layout) were empty
  placeholders** in V5: the pseudocode was an empty table cell, and the sample
  data layout had no table at all. Content was supplied in the revised copy and
  as standalone assets in `Base/docs/chapter-2-assets/`:
  `sarima-pseudocode.txt` and `sarima-sample-data-layout.csv`. The pseudocode
  was written from the implemented pipeline
  (`ML/training/scripts/modeling/train_hfce_sarima_v4.py`), and the sample
  values are the published PSA HFCE 2023 figures from
  `ML/training/config/hfce_quarterly_indices.json`.
- **Split discrepancy (needs author decision).** Chapter 2 V5 states the split
  as train 2000-Q1–2016-Q4, validation 2017-Q1–2023-Q4, test 2024-Q1–2026-Q2.
  The implemented pipeline (`train_hfce_sarima_v4.py`, `TRAIN_END="2021Q4"`,
  `VALIDATION_START="2022Q1"`) and the committed evaluation
  (`ML/models/hfce_sarima_v4/evaluation.json`) use train 2000-Q1–2021-Q4,
  validation 2022-Q1–2023-Q4, test 2024-Q1–2026-Q2. The train/validation
  boundary in the chapter does not match the code; reconcile before submission.
- **Empty heading paragraphs** (remnants of the removed subtopic titles) were
  dropped in the revised markdown.
- No "Figure #" placeholder exists in V5; all captions run Figure 1–21.
