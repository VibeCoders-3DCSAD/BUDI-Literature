## Summary

This Indonesian undergraduate thesis tests a student attendance application using black box testing with equivalence partitioning and boundary value analysis. The study designs test scenarios for input validation and boundary conditions to verify the application behaves as expected.

## Problem and Motivation

Manual attendance has drawbacks (manual rekapitulasi, lack of transparency). A GPS-based attendance application was developed, and its correctness needs to be verified through software testing.

## Method

**Design.** Software testing case study.  
**Sample.** Attendance application under test.  
**Context.** Geography: Indonesia; population: Not reported; setting: student attendance application.

- Apply black box testing methodology.
- Design test scenarios using equivalence partitioning.
- Design test scenarios using boundary value analysis.
- Execute tests and evaluate results.

## Key Findings

- Black box testing with equivalence partitioning and boundary value analysis was used to design test cases for the attendance application.
- The testing approach helps identify input validation issues at equivalence classes and boundaries.
