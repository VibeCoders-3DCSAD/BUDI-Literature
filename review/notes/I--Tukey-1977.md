`I--Tukey-1977` — Tukey (1977), *Exploratory Data Analysis*, Addison-Wesley.

## Summary

Tukey's *Exploratory Data Analysis* introduces a set of robust, graphical, and numerical methods for summarizing data. Key contributions include stem-and-leaf displays, the five-number summary (minimum, lower hinge, median, upper hinge, maximum), hinges as robust alternatives to quartiles, and the box-and-whisker plot. These methods are foundational for robust measures of spread such as the interquartile range based on hinges.

## Problem and Motivation

To provide methods for exploring data without over-relying on formal significance testing, emphasizing resistant and robust summaries and displays.

## Method

**Design.** Methodological treatise on exploratory data analysis.  
**Sample.** Not applicable (methodological reference).  
**Context.** Geography: United States; population: Not reported; setting: statistical data analysis.

- Introduce resistant summaries (median, hinges/five-number summary).
- Define hinges as letter values used to construct box plots.
- Develop graphical displays (stem-and-leaf, box plots) for data exploration.
- Emphasize re-expression and robust methods.

## Key Findings

- Hinges provide robust quartile-like values for summarizing spread.
- The five-number summary and box-and-whisker plot facilitate comparison across distributions.
- Resistant methods reduce sensitivity to outliers.

## Definitions

- **Hinge:** A letter value at depth ~ (1+m) where m is the integer part of the median depth; crudely equivalent to a quartile in exploratory data analysis (as defined in EDA).
